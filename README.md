# AI Battle Map Maker

A Foundry VTT module that generates battle maps from a text description and turns them into ready scenes.

Describe a place, choose the perspective, genre, style and mood, and pick from 4 quick layout mockups. The module then makes a finished map, measures its real size and creates the scene with the grid set in feet or metres. Before saving, you can adjust colour, contrast and sharpness for free.

- Works with any game system.
- Foundry VTT v13 or newer (verified on v14).
- Requires a [CelestiaTools Patreon](https://www.patreon.com/cw/CelestiaTools) sign-in. Each map uses part of your monthly allowance (Standard or Economy quality).

## AI usage

The battle map images are generated with AI image models (FLUX.2 and Google Gemini) through our own server. An AI vision model also checks each map for unwanted grids or text and estimates its real-world size. The map description you type is sent to these models. The module's code was written with help from AI coding assistants and reviewed by the author.
